# Prezentacja Beamer

Dziewięć slajdów pokazuje pytanie, model wahadła, syntetyczne dane, wykres, porównanie, ograniczenia i wniosek. W źródle są środowiska `frame`, `itemize`, `enumerate`, `block` i `columns`, a także tabela, wzór i wykres z [raportu](../raport/raport.tex).

Skompiluj `pdflatex prezentacja.tex` w tym folderze. Rysunek jest pobierany przez ścieżkę względną `../raport/wykres.pdf`. Gotowy plik: [prezentacja.pdf](prezentacja.pdf).

Wybrałem wbudowany motyw `Boadilla` z szerokim formatem 16:9. Jasne tło i mała liczba elementów na slajdzie pomagają odczytać wykres oraz zastrzeżenie o pochodzeniu danych.
