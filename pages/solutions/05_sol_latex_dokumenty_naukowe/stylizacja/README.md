# Stylizacja opowiadania

Wybrałem **Bolesława Prusa** jako punkt odniesienia dla karykaturalnej stylizacji prozy realistycznej. Pierwsza celowo wyolbrzymiona cecha to narrator, który zna myśli postaci i komentuje zwyczaje miejskie. Druga to dłuższe zdania oraz porównania codziennych przedmiotów z ludzkim zachowaniem. Trzecia to łagodna ironia, widoczna przy zegarze, czytelniku gazety i końcowej uwadze o sąsiedzie. Krótkie zdanie tekstu wyjściowego „Zrobiła zdjęcie paczki, włożyła kartkę do kieszeni i wyszła” zmieniłem w komentarz o człowieku rozsądnym i narzuconym terminie. Informację o szkicach drzew rozszerzyłem w refleksję o pamięci osiedla. Nie kopiowałem zdań z utworów Prusa; zachowałem wszystkie pięć wymaganych zdarzeń z tekstu zadania.

Źródło: [stylizacja.tex](stylizacja.tex). Jednostronicowy wynik: [stylizacja.pdf](stylizacja.pdf). Kompilacja: `pdflatex stylizacja.tex`.
