# Układ liniowy

Układ $2x+y=5$ oraz $x+3y=5$ zapisuję jako $Av=b$, gdzie $A=\begin{pmatrix}2&1\\1&3\end{pmatrix}$ i $b=\begin{pmatrix}5\\5\end{pmatrix}$. [Skrypt](solve_system.py) daje $x=2$, $y=1$. Podstawienie: $2\cdot2+1=5$ oraz $2+3\cdot1=5$.

Uruchom `python solve_system.py`; [results.txt](results.txt) zawiera również normę reszty $\lVert Av-b\rVert$.
