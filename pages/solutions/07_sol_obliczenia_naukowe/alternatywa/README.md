# Alternatywa: GNU Octave

[Skrypt](solve_system.m) rozwiązuje układ z [zadania Python](../uklad/solve_system.py) przez operator `A \ b` i zapisuje `octave_results.txt`. Uruchomienie: `octave solve_system.m` w tym folderze. Oczekiwany wynik to $x=2$, $y=1$.

Na komputerze użytym do przygotowania tych rozwiązań GNU Octave nie jest zainstalowany, więc nie oznaczam tego wariantu jako wykonanego ani nie dodaję pozornie wygenerowanego pliku wynikowego. W Pythonie ten sam układ rozwiązuje `numpy.linalg.solve`.
