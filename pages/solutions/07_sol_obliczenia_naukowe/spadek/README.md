# Swobodny spadek

Przyjmuję spadek z wysokości $h=20{,}0\,\mathrm{m}$ bez oporu powietrza i stałe $g=9{,}81\,\mathrm{m/s^2}$. Ze wzorów $t=\sqrt{2h/g}$ i $v=gt$ otrzymuję około $2{,}0193\,\mathrm{s}$ oraz $19{,}8091\,\mathrm{m/s}$. Jednostki wynikają bezpośrednio z obu wzorów.

Uruchom `python python_calc.py`. Program zapisuje [wynik](python_results.txt).
