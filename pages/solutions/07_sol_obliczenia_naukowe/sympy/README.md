# Rachunki symboliczne

[Skrypt](symbolic.py) rozkłada wielomian $p(x)=x^3-6x^2+11x-6$, znajduje jego zera i pochodną oraz oblicza całkę $\int_0^1x^2\,dx$. SymPy zwraca dokładny ułamek $1/3$. Przybliżenie `0.3333` ma skończoną liczbę cyfr i służy do prezentacji lub porównania liczbowego, ale nie zastępuje wyniku dokładnego. Rozwinięcie iloczynu oraz podstawienie pierwiastków stanowią niezależne kontrole rachunku.

Uruchom `python symbolic.py`. Skrypt tworzy [wyniki](symbolic_results.txt).
