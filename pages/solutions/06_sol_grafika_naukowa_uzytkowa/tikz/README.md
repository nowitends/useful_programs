# Schemat w TikZ

[Źródło](schemat.tex) składa cztery etapy z węzłów `\node` i trzech strzałek `\draw`. Styl `box` nadaje powtarzalny wygląd etapom. Skład: `pdflatex schemat.tex`; wynik: [schemat.pdf](schemat.pdf).

W kodzie łatwo zmienić jeden styl wszystkich pól albo powtarzalne odstępy. W Inkscape szybciej przesunąć pojedynczy obiekt myszą. Oba schematy przedstawiają tę samą sekwencję, ale ich układy nie muszą być pikselowo identyczne.
