# Okres wahadła

Wykres pokazuje [syntetyczne dane](wahadlo.csv) z przykładową niepewnością $T$ oraz model $T=2\pi\sqrt{L/g}$ dla $g=9{,}81\,\mathrm{m/s^2}$. Punkty ze słupkami błędów i linia przerywana rozróżniają serie także bez koloru. Osie mają jednostki; dane nie są rzeczywistym pomiarem.

Uruchom `python generuj_wykres.py`. Skrypt zapisuje [PDF](wahadlo.pdf) i [PNG](wahadlo.png).
