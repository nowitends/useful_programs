# Materiały do uzupełnienia przez prowadzącego

Ten plik służy organizacji repozytorium **przed udostępnieniem studentom**. Materiały niewymienione poniżej są już w repozytorium.

## Obowiązkowe pliki prowadzącego

- [ ] `pages/files/inkscape/bezier_01/START.svg` — pierwszy własny szablon ćwiczenia z krzywych Béziera, z zablokowaną warstwą wzorcową.
- [ ] `pages/files/inkscape/bezier_02/START.svg` — drugi szablon, analogicznie.
- [ ] `pages/files/ai/building/DSF_reference.jpg` (lub `.png`) — zdjęcie bazowe do koncepcyjnej podmiany budynku; zachować ustaloną nazwę lub zaktualizować treść zadania.
- [ ] `pages/files/ai/corrections/student_work.png` (lub PDF) — skan pracy ze zidentyfikowanymi przez prowadzącego błędami.
- [ ] `pages/files/ai/handwritten/solution.pdf` — rozwiązanie, z którego student przygotuje symulację odręcznych notatek.

## Do decyzji

- [ ] Czy temat pięciu infografik ma być jednakowy dla wszystkich studentów (wtedy dołączyć PDF z materiałem), czy wybierany samodzielnie?
- [ ] Czy zadania z AI mają być obowiązkowe w całości, czy część będzie do wyboru?
- [ ] Czy szablon TikZiT zostaje jako przygotowany przykład, czy należy go zastąpić właściwymi notatkami wykładowymi prowadzącego?
- [ ] Ustalić terminy i sposób feedbacku przez GitHub Issues.

**Nie zastępowano zdjęcia DSF, szablonów Béziera ani skanów fikcyjnymi odpowiednikami.** Można natomiast przetestować strukturę repozytorium oraz pozostałe zadania na dołączonych danych demonstracyjnych.
