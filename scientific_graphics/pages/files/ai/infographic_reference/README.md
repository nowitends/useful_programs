# Infografika referencyjna — zadanie AI 5

`reference_en.png` to anglojęzyczna infografika **niezwiązana z tematem przyszłego wykładu**.

- Najpierw przełóż jej tekst na polski, zachowując kompozycję.
- Następnie wykorzystaj **styl**, a nie temat referencji, do serii pięciu infografik wykładowych.
- `reference_en.svg` jest źródłem wektorowym i może służyć do analizy kompozycji lub ręcznej poprawy tekstów.
