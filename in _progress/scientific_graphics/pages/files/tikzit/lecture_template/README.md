# Projekt startowy TikZiT / LaTeX

Projekt zawiera plik `main.tex` z **trzema miejscami na rysunki** oraz `styles.tikzstyles`.

1. Skopiuj zawartość tego folderu do własnego `pages/solutions/03_sol_tikzit/`.
2. Utwórz diagramy w TikZiT, zapisz je w `figures/`.
3. Zastąp w `main.tex` trzy polecenia `\missingfigure{...}` odwołaniami `\input{figures/nazwa.tikz}`.
4. Skompiluj projekt za pomocą `pdflatex main.tex` (dwukrotnie, aby odświeżyć odwołania).
5. Dołącz końcowy `main.pdf` do repozytorium.

**Uwaga:** dołączony dokument jest przygotowanym przykładem. Prowadzący może podmienić tekst na własne notatki przed rozpoczęciem zadania.
