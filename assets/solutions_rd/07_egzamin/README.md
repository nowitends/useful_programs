# Status zadania 7

egzamin.tex obejmuje wszystkie 62 zagadnienia z [listy UWr](https://wfa.uwr.edu.pl/wp-content/uploads/sites/216/2025/10/Pytania-lic-Fizyka-I-st.pdf): 37 z fizyki ogólnej, 17 z fizyki teoretycznej i 8 z ekonofizyki.

To zwięzły konspekt. Każdemu zagadnieniu przydzielono około pół strony układu, ale tekst nie wypełnia jeszcze merytorycznie wymaganych co najmniej pół strony. Do pełnego wykonania zadania trzeba rozwinąć każde zagadnienie o wyprowadzenia i przykłady.

Kompiluj egzamin.tex przez pdflatex; pozostałe pliki .tex są włączane za pomocą polecenia LaTeX input.
