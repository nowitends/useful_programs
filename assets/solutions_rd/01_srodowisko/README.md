# Zadanie 1 — środowisko

Konto Overleaf wymaga samodzielnego założenia i potwierdzenia przez studenta. Nie zakładałem konta ani nie tworzyłem projektów w cudzym profilu.

W tym środowisku dostępna jest lokalna dystrybucja MiKTeX z poleceniami pdflatex, xelatex, lualatex i bibtex. Dokumenty w tym folderze rozwiązań kompilowano lokalnie programem pdflatex (bibliografię w zadaniu 6 dodatkowo przez bibtex). Nie zweryfikowano instalacji edytora TeXstudio ani konfiguracji VS Code u studenta.
