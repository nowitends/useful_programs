# Status zadania 4

publikacja.tex i publikacja.pdf są **aneksem dydaktycznym** do [oryginalnej pracy](https://arxiv.org/abs/1110.6812), a nie przeredagowanym pełnym artykułem. Oryginalni autorzy są wskazani w aneksie. Archiwum plików źródłowych TeX z arXiv nie udało się pobrać w tym środowisku; bez niego nie można rzetelnie oznaczyć wszystkich zmian w pełnym tekście i skompilować jego zmodyfikowanej wersji.

Aneks zawiera przykłady poprawek językowych w kolorze niebieskim, uzupełnienia merytoryczne w czerwonym i propozycję usunięcia w zielonym. Skrypt analiza_numeryczna.py tworzy wykres analiza_numeryczna.png i drukuje błąd numeryczny dla trzech kroków całkowania. Analiza rozwiązuje zredukowane równanie Friedmanna, a nie pełny problem pól cechowania.
